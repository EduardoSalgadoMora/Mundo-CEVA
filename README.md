# Mundo CEVA · versión lite (web)

Versión web de prueba. Funciona en cualquier navegador, pero el progreso se borra al cerrar la pestaña.
Para guardarlo, instala la app Android (`Mundo-CEVA.apk`).

## Publicar en GitHub Pages
1. Crea un repositorio público (por ejemplo `mundo-ceva`).
2. Sube todo el contenido de esta carpeta a la raíz del repositorio.
3. En el repositorio: Settings → Pages → Source: "Deploy from a branch", rama `main`, carpeta `/ (root)`.
4. En un minuto estará en `https://TU-USUARIO.github.io/mundo-ceva/`.

Contraseña de configuración por defecto: 1234.
